# 领域说明

赛事天气、路线和报名人数会影响赞助权益、场地合同与供应商应付。履约日、发票日、支付日和赛事变更日可能错开，预算记录要同时保存承诺与实际完成量。预提、红字发票和审批时限属于长期留存的信息。

`reference/domain.json` 保存公开的赛事事件、分层账、成本中心和发票/审批状态。正式记录使用稳定标识，并区分业务时间（`occurred_at`）、接收时间（`received_at`）和版本（合同 `version`、事件 `seq`）。

结算口径、发票族（拆票/红字/重开）、取消冻结、支付幂等、差异桥与审批队列的完整规则见 [`settlement.md`](settlement.md)。
